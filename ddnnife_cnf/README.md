# `ddnnife_cnf`

> A DIMCAS CNF implementation.

This is a very simple implementation for representing CNF formulas.
At its current state, it can only be used for representation and displaying a formula.
It is intended for usage by [ddnnife][ddnnife].
See the [documentation][docs] for details.

[ddnnife]: https://github.com/practical-kc/ddnnife
[docs]: https://docs.rs/ddnnife_cnf/latest/ddnnife_cnf
